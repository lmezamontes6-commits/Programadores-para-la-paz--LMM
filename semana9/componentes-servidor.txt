Sistema operativo:
Es el software principal que administra los recursos del computador. Permite ejecutar aplicaciones y gestionar el hardware.

Node.js:
Es un entorno de ejecución que permite correr código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y respuestas que reciben los usuarios.

Puerto:
Es un punto de comunicación que permite al servidor recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan eventos y actividades del sistema. Ayudan a monitorear el funcionamiento y detectar errores.
