La autenticación o login es el proceso mediante el cual un usuario se identifica en una aplicación con un nombre de usuario y una contraseña. Esto permite verificar su identidad antes de acceder a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes dentro del sistema. Solo los usuarios autorizados deben acceder a estas funciones. No deben exponerse públicamente contraseñas, documentos de identidad, direcciones, teléfonos, correos electrónicos, tokens, claves de API ni otros datos sensibles de la comunidad. De esta manera se protege la privacidad y la seguridad de la información.
